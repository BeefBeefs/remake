Readme

Thank you for purchasing ShadowFlare: Episode Three.

If you use Windows XP or Windows 2000, you must log on as an Administrator before you can setup ShadowFlare.  To setup ShadowFlare, run SFSetup.exe.  

You must have the ShadowFlare: Episode Two Version 2.002.000 installed before installing Episode Three. The version is displayed on the bottom right-hand corner of the initial screen after starting ShadowFlare.

When you have finished Episode Three, do not delete the game data because you might want to use it when you proceed to Episode Four.  You can find information about Episode Four at:
http://www.shadowflare.us/download.htm

For further information, please visit the ShadowFlare web site:
