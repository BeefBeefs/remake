ShadowFlare: Episode One
Version 2.001.000
Readme

Thank you for downloading ShadowFlare: Episode One.

If you use Windows XP or Windows 2000, you must log on as an Administrator before you can setup ShadowFlare.  To setup ShadowFlare, run SFSetup.exe.  

You don't need to have the ShadowFlare Pre-Scenario Demo installed before installing Episode One.  However, even if you have already played the ShadowFlare Pre-Scenario Demo, you can still safely install Episode One without deleting your previous game data.

When you have finished Episode One, do not delete the game data because you might want to use it when you proceed to Episode Two.  You can find information about Episode Two at:
http://www.shadowflare.us/download.htm

For further information, please visit the ShadowFlare web site:
http://www.shadowflare.us/
