# Playtest scripts (Playwright)
Serve `public/` (`cd public && python3 -m http.server 8123`) then run with node (playwright is imported from /opt/node22/lib/node_modules; adjust the import for other machines).
- `smoke.mjs` loads every scenario and counts console errors / 404s.
- `kill.mjs` fights goblins in scenario 0 and checks exp, gold and drops.
- `connectivity.mjs` flood-fills each Episode 1 scenario from every entry point (`edges.json` = inbound entry ids from the scripts) and writes `/tmp/reach.json` with the exits, NPCs and bosses reachable on foot.
- `route.mjs` drives the real game through the Episode 1 exit chain (start -> Garam Goblin room) via `scene.exit()` and kills the boss.
- `menus.mjs` seeds two saves, loads one through Title -> LOAD DATA -> mode window, checks slot handling and DELETE. `newgame.mjs` checks legacy-save migration and New Game slot assignment.
- `gamemenu.mjs` opens the Game Menu with Esc in a dungeon, toggles settings, checks darkness and closing.
- `belt.mjs` uses belt items with keys 1-8 / right click (Tablet, Capsule, Vitality Source, Apple).
- `magic.mjs` casts Fire Bolt-style spells at a goblin with a clear line of fire; `tabs.mjs` checks F-keys, M, tab clicks and Esc for the Status/Magic windows; `mapsave.mjs` also opens the map and checks the saved magic/explored data.
- `companion.mjs` hires Kerberos through the keeper's dialog (Check Status / Swap Dogs), then fights, Space mode, Meat, a mine, power-up, TAB jump/dash/status and the save data. `companion-tab.mjs` checks TAB+click jump and TAB+right click dash on open ground.
- `statue.mjs` stands next to a type-5 statue plate in scenario 00010001 and checks that status 6 fires and the plate's switch variable toggles.
- `bosses.mjs` kills every monster of the boss-room scenarios through the damage path and checks the polled quest completion; `quests.mjs` fires all status-4 kill handlers of each scenario.
- `commander.mjs` walks the Cold Svalt commander's quest ladder (quests 4-10); `town.mjs` talks to every Remote Town NPC for several quest states; `talkall.mjs [scenarios]` auto-talks to every scripted object and reports stuck dialogs / warnings.
- `turret.mjs` stands in the Garam Goblin room and checks that the pillar turrets shoot bolts that hurt the hero.
- `repair.mjs` — Malse identify/repair services, durability wear.
- `heal.mjs` — Syria healing (HP/MP/dog).
- `equipsets.mjs` — I/II equipment sets, unidentified equip block.
- `shaman.mjs` — shaman bolts + stagger.
- `warehouse.mjs` — store/take items in the town warehouse chest.
- `career.mjs` — class change as decoded from the exe: level 5 makes the Mercenary a Warrior; each later level-up offers Wizard (>= 20 % spell hits), Hunter (>= 30 % bow-gun hits) or Warrior (>= 50 % classes 0/1/3) from the hits since the last level; counters reset.
- `twohand.mjs` — two-handed weapons disable the shield; bow attacks.
- `special.mjs` — gargoyle bolt and golem slam.
- `fx.mjs` — script effect sprite spawning.
- `shiftclick.mjs` — Shift+click attack in place, Ctrl run, CapsLock set swap.
- `triple.mjs` — Warrior Triple Attack.
- `attrs.mjs` — attribute medicines and status values.
- `itembonus.mjs` — variant item bonuses (attack %, speed %, attribute levels) and tooltips.
- `wheel.mjs` — monster attributes and the weakness wheel multiplier.
- `allspells.mjs` — casts every spell, reports damage / stun / buffs; `spellpet.mjs` — Moon, Explosion, Identify, shields and Counter Burst; `gearslots.mjs` — HP/MP gear slots, M.Defense, harmony.

- `episodes.mjs [eps] [limit]` loads every scenario of Episode N's patch with `?ep=N` (fresh page each) and reports 404s / page errors; all of Ep1-4 pass.
- `fxslots.mjs` checks the full item bonus block (tooltip lines of Recovery / Gamble / Power Bracelet / Gilgamesh / Wildcat Bow ..., life and mental recovery per second, gold, strength).
- `learn.mjs` walks the spell learning rule (class history x Table.Tbd 100-107): Plasma at 5 Mercenary levels, Wizard spells after the change, etc.
- `upgrade.mjs` — an Episode-1 save is continued in Episode 3 from the LOAD DATA screen's "Continue in Episode N >" picker (gold and map kept, `Data.ep` = 3).
- `compgear.mjs` — Companion Evasion gear makes the dog dodge, its status shows Hit Rate / Evasion.
- `spelltables.mjs` — real spell data: MP cost (Table 16), Heal % (17), exp per level (27, +1 exp per cast, cap 20), cast-time multiplier (20).
- `epscripts.mjs` — fires every script handler (talk chains, kills, zones, polls) of every scenario of Episodes 2-4 and reports unimplemented sentence types / page errors (none found).
- `epexits.mjs` — every map exit (sentence 17) and warp-gate row of an episode leads to a scenario of its data chain.
- `epbind.mjs` — every script handler's character number (zone 10xxxxxx, NPC 12xxxxxx, monster kill 14xxxxxx) is matched against the scenario's zones / actors; lists handlers without a counterpart.
- `epquests.mjs` — carries the script state through all scenarios of an episode with a level-40 hero and answers every dialog with options 0, 1, 2; reports how many quests got started / completed by the scripts alone (needs items and drops for the rest, so it is a lower bound).

- `epitems.mjs ep [out.json]` - fires every handler of an episode's scenarios and records the quest items the scripts ask for and the chest drop levels used; compare with Tables 30/31 (see PROGRESS "Quest item sources"). Needs the server on :8123.
- `giveitem.mjs` - sentence 75 (reward item) puts quest items into the bag.
- `blackjack.mjs` - Tower of Ordeal Black Jack: hand values, win/lose spread, and the script round trip in 99000023 (pay, hand, result block, win counter).
- `questsent.mjs` - sentences 67-71: quest spell grant, exp percentage, offered profession read/write.
- `touch.mjs` - touch controls with emulated touch (stick, ATK, menu buttons, canvas tap, fullscreen toggle).
- `touchname.mjs` - tap the name field on the new-character screen: the hidden input takes focus and edits the name.
- `equipdraw.mjs`: equips armor/shield/weapon combinations and screenshots the hero (look at /tmp/equip_N.png).
- `questpoll.mjs` - the nine accepted-only quests: set state 1, kill all monsters of the completion scenario, expect state 2 (8 of 9; 28 uses `quest28.mjs`).
- `quest3.mjs [scenario] [quest]` - single-quest version of the kill-all completion check.
- `quest28.mjs` - quest 28 completes on arriving through exit entry 2 (sentence 50).
- `epplay.mjs [ep]` - ordered-play quest sweep (see docs/PROGRESS.md); env CHEAT, LEAVES, TALKS, ROUNDS, PASSES, REVISIT, ONLY.
- `boardfuzz.mjs <ep> <scenario> [trials]` - random-flag fuzz of one scenario (SHOW=1 prints the flag sets that started each quest).
- `tools/guardchain.py <ep> <scenario> <block> [sets]` (not a playtest, a static helper): prints the guard conditions that lead from a script block to its status entries; `sets` lists guarded `V1 := const` conversation-chain setters. Quest start paths for 12-14, 34, 37, 38, 40 were driven in the VM with seeded globals (see docs/PROGRESS.md).
- `missing404.mjs [ep]` loads every scenario of the episode and lists each 404 resource with the scenario that asked for it (only `*_sdw.json` shadow sets of a few objects 404; zones.ts treats them as optional).
- `talkseed.mjs <ep> <scenario> "<k=v,...>" <quests>` seeds globals (`11:85=11`, `q:17=2`), talks to NPC 12000000 three times with the hand-in check stubbed true and prints quest states and the items asked for (edit the char id in the script for other NPCs). `ladder.mjs <ep> <scenario> <global> <max> <quests>` steps one stage global through its values by talking to the NPCs and shows how it advances.
- `warnscan.mjs [ep]` loads every scenario of the episode for 2.5 s each and lists distinct console warnings / errors / page errors (none at the last run: 209 scenarios, 0 messages).
